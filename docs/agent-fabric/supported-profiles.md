# Convergence delivery and supported execution profiles

Production implementation and qualification are separate. A source-complete profile is not a claim that every device, credential or failure scenario has been operated.

The desktop supports managed and selected UAR instances, durable local teams, BossFang delegation to that same selected executor, explicit approval and connector receipts. Peer synchronization is restricted to personal data and current endpoint-bound consent. Embedded/home/cloud placement uses one UAR execution and persisted source frames. Representation is disclosed, owner-asserted assistance with the current bounded readonly grant; portable office roles contain no human identity or consent.

The authenticated capabilities response includes the versioned federation profile. The Rust SDK admits only the configured HTTPS/loopback endpoint with credentials, checks required features and returns an instance snapshot. That snapshot explicitly grants no effect authority. The resource runtime still checks current identity, task/membership fences, approval and scope. Registry advertisements are discovery only. Distributed team members and automatic takeover are refused; they do not silently select another executor.

## Release operation

At a completed delivery boundary, use Node22+:

    node scripts/convergence-release-report.mjs --sources build/integration-sources.json --artifact dist/The-Boss-2.2.25-mac-arm64.dmg --out dist/convergence-operation.json

Optional operation receipts are a JSON array of source-bound records with actual measurements: acceptedTasks, humanCorrections, costMicrounits, latencyMs, duplicateEffects, unknownEffects, administrationMs. Missing values remain null. A baseline can be supplied separately; incomparable baselines must not become a performance claim. Authenticated discovery can be attached with --runtime-url and --credential-env; the credential value is never written to the report.

The report hashes real local artifacts, retains input provenance and distinguishes observations from certification. It does not dispatch tests, start services, create issues, perform takeover or infer acceptance from a health response. The four Mac/Windows installers follow the existing release publisher and website process. Linux remains excluded. Previously accepted2.2.24 evidence retains its original source identity; new source acceptance remains separately recorded.
