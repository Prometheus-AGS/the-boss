# Workflow operator surface

Operation: refinement of existing Teams. Mode: Operate. Incumbent DESIGN.md, PRODUCT.md, .impeccable.md, shared components and semantic token catalog govern this surface.

The shortest path is Teams → select an existing team → Workflows → installed definition → bounded feedback → classify/draft members and reservations → Start. Saved runs can be inspected without a selected team. A durable wait displays the exact plain-text title/body, pinned artifact identity and explicit internal-only notice. Accept, reject and cancel send exact wait/artifact/revision; Cancel/Recover outside a wait require a reason. Unresolved accounting is displayed separately from disposition.

Input and selection values survive a failed command. Identical in-session retries preserve command identity. The runtime owns durable results and reload, and the UI does not claim a transport failure means a command failed. Refresh is always the authoritative recovery path; old snapshot responses cannot replace a newer command receipt.

Keyboard reading order follows headings, definition selection, feedback, each member and its numeric budgets, Start, saved-run selection, draft and decisions, recovery reason/actions, and optional details. Shared Select/Button/Input/Textarea provide native/shared keyboard behavior; fields have explicit labels, status uses a polite live region, errors use alert, and details have inset visible focus. Long identities wrap and numeric fields collapse from three columns to one at narrow widths. No new motion or palette is introduced.
