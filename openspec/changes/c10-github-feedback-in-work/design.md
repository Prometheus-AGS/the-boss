# Ownership and contracts

UAR owns durable intake, workflow execution, explicit issue approval, dispatch fence and effect outcomes. The Boss owns Work UI, protected credential storage and fixed GitHub HTTP transport. The authored customer-feedback package includes an immutable workflow whose product role classifies and documentation role drafts. Required capabilities and exact workflow bindings are packaged with the team; existing instances retain their old immutable definition.

Publication approval is distinct from internal artifact acceptance. It binds owner, workspace, repository, binding revision, workflow artifact ID/digest and exact outgoing payload digest. The host consumes one dispatch lease. An uncertain HTTP outcome is persisted and reconciled by the intake marker; it is never treated as permission to resend. Credentials remain outside portable definitions and ordinary IPC responses.
