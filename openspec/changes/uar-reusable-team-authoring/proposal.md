# Reusable UAR teams in The Boss

## Why
The Work surface can run an installed team, but its only setup path installs one fixed coding preset. Operators cannot name, revise, or configure coding and product/design teams through The Boss.

## What changes
- Add guided, versioned team authoring in UAR administration, with coding and product/design starting configurations, team and member instructions, role-specific model choices, and scoped skill/tool selections.
- Deploy immutable UAR definition packages and separate private workspace bindings through the existing catalog and approval boundary. Existing runs retain their pinned package digest.
- Make deployed teams selectable from Work and provide a packaged operation procedure that creates, deploys, runs, revises and reopens a team.

## Scope
This is the `reusable-mixed-teams` customer delivery covering C15.1, applicable C15.3 and C16.1–3. It uses the existing UAR team kernel. Broad cross-harness qualification, a second scheduler, connector templates, portable credentials and implicit tool authority are outside this change.
