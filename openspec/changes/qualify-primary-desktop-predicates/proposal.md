# Proposal

## Why

The 66 remaining Boss checklist lines combine obsolete implementation prescriptions, existing evidence, missing operations and deferred platform clauses. Treating each line as a fresh release gate repeats builds without improving the supported Mac ARM64 and Windows x64 experience.

## What Changes

- Produce a complete 66-row predicate map and an evidence applicability register for the existing 2.2.38 candidate.
- Propose explicit dispositions for obsolete procedures and superseded architecture. No original requirement or checkbox changes until approved.
- Qualify only missing customer operations, combining overlapping clauses in isolated application profiles. Reuse passing operations and the already-published installers.
- Obtain missing independent artifact review without repeating preset inference, builds or publication.
- Preserve separate code completion, portfolio qualification and candidate-specific customer acceptance. Keep optional specialist, advanced recovery and nonpriority platform criteria pending.
- If an operation demonstrates a production defect, record it and propose a bounded corrective change; do not automatically build another candidate under this qualification-only plan.

## Capabilities

### New Capabilities

None. This change plans qualification and documentary reconciliation of existing capabilities.

### Modified Capabilities

None in this planning change. Proposed changes to historical acceptance prescriptions require operator approval and explicit amendments in the owning original changes. They are not applied here. Accordingly, this documentation change sets `skip_specs: true`.

## Impact

Planning artifacts only. No production code, dependencies, schemas, installers, website deployment or generated KBD projections change. Original code remains 61/61 tasks and 20/20 changes; portfolio qualification remains 43/61 terminal items (42 qualified and one historical skipped duplicate). The 66 Boss checklist lines are a separate local inventory, not another portfolio denominator.

The convergence phase remains administratively closed and Cadence retired. Approval of this proposal would authorize bounded qualification/reconciliation work, not restart the closed phase or create a new Cadence delivery.
