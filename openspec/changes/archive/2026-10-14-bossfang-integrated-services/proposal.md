# Integrated BossFang services

## Why
The installed dashboard opens without applying its selected UAR connection, and private key-value memory is incorrectly sufficient to appear ready despite no shared Surreal Memory connection. The operator approved this repair on 2026-10-11.

## What Changes
Persist automatic connection intent and a private personal workspace; apply selected UAR and discovered memory connections; expose live models and independent readiness. Add scoped shared-memory tools through the authenticated host boundary while preserving private memory.

The operator-approved continuation adds a unified UAR target catalog and resolver: installed agents, verified configured models through the default agent, and explicit policy-admitted model overrides. BossFang's dashboard delegates these explicit targets through the full-run bridge instead of nesting UAR execution inside its native LLM loop. The selector groups agents and models and preserves unavailable saved choices. Verification includes cross-runtime recall after quitting and restarting The Boss; the earlier BossFang-only restart does not satisfy it.

## Capabilities
### New Capabilities
- integrated-bossfang-services: Applied service connections and scoped memory.

## Impact
The Boss lifecycle, IPC, preferences, UI/locales, trusted MCP boundary; BossFang model catalog and native shared-memory tools. No new daemon, project-directory grants, database migration, or silent provider changes.
