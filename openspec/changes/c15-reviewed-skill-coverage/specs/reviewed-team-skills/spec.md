# Reviewed team skills

## ADDED Requirements

### Requirement: Trusted reviewed closure
Selected skill coverage MUST bind exact installed identity, trusted source, complete required relative-path closure and current bytes. Application-owned mini uses the packaged baseline; full pack uses its existing signed generation, trust store and target receipts. Writable runtime metadata and renderer input cannot self-certify.

#### Scenario: Selected bytes change
- **WHEN** a disposable selected closure differs from its reviewed source
- **THEN** new reviewed binding is refused with actionable status; existing identity is not silently rewritten.

### Requirement: Private binding and existing authority
Coverage MUST travel through the existing authenticated owner/workspace private binding, never portable definitions or credentials. Required tools MUST fit the installed member host scope; actual effects remain under existing live authority and approval.

#### Scenario: Tool outside member scope
- **WHEN** a required tool exceeds the member host scope
- **THEN** binding is refused without issuing a permit.

### Requirement: Usable administration
The existing skill selector MUST distinguish reviewed, unreviewed and blocked coverage, explain repair actions and localize new labels in every existing locale.

#### Scenario: Complete packaged operation
- **WHEN** the increment is complete
- **THEN** build Mac ARM64, launch its actual package and operate reviewed mini/full selection and deployment, tamper refusal, out-of-scope refusal and the existing approval route; consume previous handoff receipt separately.
