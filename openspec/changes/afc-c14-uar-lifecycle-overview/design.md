# Design

Use the existing trusted main-process UAR adapters and typed IPC. `prometheus.uar.lifecycle.snapshot` accepts a configured service instance identity and registered workspace identity. Resolve and admit that endpoint once, then pass it into read adapters; do not change the globally selected execution instance. Main-process credentials stay bound to their configured instance and never enter renderer responses. Include instance identity in read deduplication keys. Return each source's availability, scope and timestamp; the composed response explicitly remains non-atomic. Do not create a second runtime store or write UAR state.

Place the overview in `/settings/uar` using the established settings navigation and visual system. Preserve inspection selectors in `adminInstanceId` and `adminWorkspaceId` search fields. Keep existing detail controls as the action owners and prevent a selected external inspection from opening global-runtime actions as if they targeted that instance. Render task dependency and assignment information from team task records; show binding activation support, measured budget use, and observer cursors/backlog/gaps with clear unknown states. Translate new UI copy in every existing locale and preserve keyboard and narrow-screen use.

The completed delivery boundary builds a Mac ARM64 package, launches it with an isolated profile, and operates the overview against a running UAR with a team/task/workflow. A source-level view alone is not operational evidence. Release publication and Windows installed acceptance remain separate receipts.
