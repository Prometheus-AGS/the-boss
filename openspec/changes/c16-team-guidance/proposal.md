# Proposal

## Why

Approved initiative task C16.3 requires novice guidance, a single-agent
alternative, role-combination rules, honest model/cost classes and regulated-work
applicability. The existing editor hides creator alternatives and discovery in
raw JSON and omits help for the three original presets.

## What Changes

- Present outcome → minimal roles → scope/outputs → resources → save/deploy.
- Link ordinary single-agent Work without changing team membership rules.
- Render existing creator alternatives, discovery and role resources readably.
- Expose reviewed strength, nullable prices and source/freshness metadata.
- Explain role combination, independent evaluation and regulated applicability.
- Translate copy in all thirteen locales and prepare a real packaged operation.
- Prepare 2.2.21 package version, stable release history and bundled notes together.

## Impact

Renderer composition, optional typed guidance fields, locale catalogs, existing
packaging metadata, local documentation and operation driver only. No new IPC,
database schema, executor, resource authority, dependencies or skill-pack edits.
Work-ahead `c16-team-guidance-work-ahead-20261008` contributes to canonical
`afc-c16-specialist-marketing-product-and-design-teams/C16.3`; this source change
does not add a separate canonical task or mark runtime acceptance complete.
