# Proposal

## Why

The Boss offers Coding and Product/design presets with at most six members. Approved C16.1 requires a coordinator plus UI/UX, mobile, security, product, documentation and separate code-review specialists, with inspectable member scope and delivery instructions.

## What Changes

- Add a bounded seven-member Specialist delivery preset after confirming native capacity.
- Add editable project-relative scope, output and evidence instructions with empty defaults for older teams.
- Persist these fields in existing immutable authoring records and compile their text into member instructions/source identity.
- Translate every new editor label and prepare one real packaged author/save/deploy/run/reopen operation.

## Capabilities

### New Capabilities

- `uar-specialist-team-authoring`: bounded specialist preset and member delivery instructions through the existing reusable-team lifecycle.

### Modified Capabilities

None. Existing reusable-team authoring remains active and its model/resource/reviewed guidance behavior is preserved.

## Impact

Shared authoring schema, main package compiler, existing Settings member editor/panel and renderer locales; a dedicated packaged operation using existing helpers. No dependency/version, scheduler, model metadata, grants, connector, cross-harness qualification, C16.2/C16.3 or service changes.

This is admitted work-ahead `c16-specialist-authoring-work-ahead-20261008`, not a new phase or iteration. Root owns builds, operation execution, review and promotion after current delivery succeeds. Native Windows acceptance remains pending.
